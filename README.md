# ⚡ Hex-Board: League of Legends Soundboard

Una aplicación web ligera (PWA) estilo soundboard con temática de League of Legends. Diseñada con una interfaz Hextech e implementando un algoritmo de mezcla aleatoria sin repetición.

## 🛠️ Tecnologías Utilizadas
* **Backend:** Python con Flask (servido con Gunicorn en producción).
* **Frontend:** HTML5, CSS3 puro (diseño Hextech) y Vanilla JavaScript.
* **Hosting:** Render (Despliegue continuo desde GitHub).

## ✨ Características
- **Interfaz Hextech:** Paleta de colores, bordes y efectos visuales (glow) inspirados en el cliente de LoL.
- **Algoritmo Fisher-Yates:** El reproductor en JavaScript mezcla la lista de reproducción dinámicamente y garantiza que **ningún audio se repita** hasta que se haya escuchado la biblioteca completa.
- **Instalable (PWA-ready):** Puede añadirse a la pantalla de inicio de iOS/Android para comportarse como una aplicación nativa a pantalla completa.
